# 교실 대소동 — CLASS BUSTER

과학고·학교 생활을 배경으로 한 **학생용 비잔혹 FPS 프로젝트**입니다. DOOM 엔진(Chocolate Doom 기반 `doomgeneric`)을 WebAssembly로 실행하며, 과목 마스코트·교내 연구 공간·학습 도구를 활용하는 방식으로 원작의 진행 구조를 재해석했습니다.

## 이번 디자인·오류 수정판

- 시작 화면을 과학고 연구동·천체 관측실·학교 문장(책 + 원자 모형) 중심의 과학 아카데미 디자인으로 교체했습니다.
- 화면 비율을 16:10 게임 캔버스에 맞추고, 작은 화면에서도 안내·감도·전체 화면 버튼이 잘리지 않도록 조정했습니다.
- 메뉴·난이도·학기·레벨 사이 이동 화면·도움말·크레딧·엔딩 문구를 다시 정리하고 한글 그래픽으로 교체했습니다.
- 1인칭 장비 그래픽을 연필 발사기, 지우개 발사기, 삼색 형광펜, 종이비행기 발사기, 레이저 자, 원자 모형 장치, 연필깎이로 변경했습니다. 총기·칼날 실루엣은 사용하지 않습니다.
- 상태바를 실험 장비 계기판처럼 재구성하고, 열쇠 아이콘을 색상별 학업 메달로 바꿨습니다.
- 피·해골·지옥·불꽃 계열의 일부 텍스처를 파란 잉크, 게시판, 실험실 패널, 비커 속 색소/젤 표현으로 교체했습니다.
- 적 캐릭터의 붉은 발광 눈과 불꽃 장식 일부를 청록색 장비 표시등·연구실 신호등으로 바꿨습니다. 적은 과목 마스코트이며 쓰러질 때 기절·종이 조각·색종이 효과로 표현됩니다.
- 브라우저 런타임의 파일 불러오기 예외 처리, 오디오 초기화 실패 처리, 마우스 포인터 잠금 실패 안내, 전체 화면 오류 안내를 보강했습니다.
- 마우스는 DOOM식 Pointer Lock을 사용합니다. 화면을 클릭하면 포인터가 고정되고 `movementX` 상대 이동량으로 시점이 회전합니다. 드래그 회전 대체 모드는 사용하지 않습니다.

## GitHub Pages로 플레이하기

1. 이 폴더의 **내용물 전체**를 저장소 최상위에 올립니다. `index.html`, `runtime.js`, `classbuster.wasm`, `classbuster.wad`가 같은 폴더에 있어야 합니다.
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 를 선택하고 저장합니다.
3. 배포가 끝나면 `https://<아이디>.github.io/<저장소이름>/` 에 접속합니다.

`index.html`을 파일 탐색기에서 더블클릭하면 브라우저 보안 정책 때문에 실행되지 않습니다. 로컬 테스트는 이 폴더에서 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속하세요.

`classbuster.wad`는 약 28MB입니다. GitHub 웹 업로드는 단일 파일 25MiB 제한에 걸릴 수 있으므로 Git 명령어, GitHub Codespaces 또는 GitHub Desktop으로 전송하세요.

```bash
git init
git add .
git commit -m "CLASS BUSTER"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

## 번역 범위 안내

타이틀·메뉴·난이도·학기·인터미션 레벨 이름·도움말·크레딧·엔딩·웹 시작 화면은 한글 그래픽으로 교체했습니다.

단, **획득 직후 짧게 나타나는 메시지와 자동지도 상단의 일부 레벨 이름 등은 기존 엔진 C 코드의 문자열**입니다. 이 문자열은 엔진의 8비트 내장 글꼴로 그려집니다. 현재 배포된 `classbuster.wasm`을 다시 빌드하지 않은 상태에서 UTF-8 한글 문자열만 넣으면 글자가 깨질 수 있으므로, 해당 엔진 문자열까지 완전한 한글로 바뀌었다고 표시하지 않았습니다. 이를 완전히 한글화하려면 C 엔진의 한글 글꼴 렌더러와 WASM 재빌드가 추가로 필요합니다.

## 폴더 구성

- `index.html`, `runtime.js`, `classbuster.wasm`, `classbuster.wad` — 브라우저 실행 파일
- `engine/` — DOOM / Chocolate Doom / doomgeneric 엔진 C 소스
- `tools/` — 그래픽·사운드·WAD 생성 도구 (`build_wad.py`, `art3d.py`, `art2d.py` 등)
- `build.sh` — 엔진 WebAssembly 재빌드 스크립트 (`pip install ziglang` 필요)

기존 WAD를 과목·과학고 테마로 다시 꾸미려면 다음 명령을 사용합니다.

```bash
python3 tools/retheme_existing.py classbuster.wad classbuster-themed.wad
```

Freedoom 원본 데이터에서 새 WAD를 처음부터 만드는 경우에는 다음과 같이 실행합니다.

```bash
python3 tools/build_wad.py freedoom1.wad classbuster.wad
```
